# NETPHIM - Movie Streaming Aggregator

A premium movie streaming website built with React (Vite) and Node.js (Express). 
Integrates data from **Ophim** and **KKPhim**.

## Features
- **Premium UI**: Dark mode, glassmorphism, smooth animations.
- **Aggregated Data**: Fetches movies from two major sources.
- **Search**: Real-time search across both providers.
- **Player**: Embedded video player with episode selection.
- **Responsive**: Works on desktop and mobile.

## Tech Stack
- **Frontend**: React, Vite, Framer Motion, Lucide React, Axios.
- **Backend**: Node.js, Express, Axios, CORS.

## Getting Started

1. **Install Dependencies**:
   ```bash
   # In root directory
   cd backend && npm install
   cd ../frontend && npm install
   ```

2. **Run the Project**:
   Double click `start.bat` or run:
   ```bash
   # Backend
   cd backend && npm run dev
   # Frontend
   cd frontend && npm run dev
   ```

3. **Open Browser**:
   Navigate to `http://localhost:5173`
